## Featured project: [Crux](https://github.com/ryanlamcw015/crux)

**Is it good out there?** Crux answers the question every climber asks before a trip.

**[Live demo](https://crux-web-tau.vercel.app)** (one click, no signup) · **[API docs](https://crux-api-psi.vercel.app/docs)**

- **Conditions Score:** an hour-by-hour 0–100 rating for the next 72 hours. It combines Open-Meteo weather, the last 48 hours of rain, solar position (NOAA equations) and a drying model for each rock type. Wet sandstone is always "No-go" because climbing it breaks holds.
- **~220,000 real routes** from OpenBeta across 5,000+ areas, searchable on an interactive map.
- **PostGIS geospatial search** for "partners near me", with a SQLite fallback so the whole app runs locally with zero setup.
- **Logbook and progression analytics:** grade pyramids, monthly send trends, streaks and personal bests.
- **Social:** friends, an activity feed with kudos, and a partner finder.

`Python` `FastAPI` `PostgreSQL/PostGIS` `SQLAlchemy` `Alembic` `pytest` `React 19` `TypeScript` `Tailwind` `Leaflet` `Vercel` `Neon`
